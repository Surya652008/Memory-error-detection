# Memory Error Detection Dashboard

A college-project website for simulating memory operations and detecting data corruption using even parity.

## Run
No installation is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Go to **Simulator**.
4. Enter binary data and choose an error type.
5. Click **Run Simulation**.

## Features
- Dashboard statistics
- Even-parity calculation
- Single-bit, multiple-bit and random error injection
- Memory map
- Error logs
- Synthetic memory data
- Analytics graph
- Responsive design

## Project concept
Original Data → Parity Generation → Memory Storage → Error Injection → Parity Recalculation → Error Detection
