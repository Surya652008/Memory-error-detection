About the Project

Memory Error Detection Dashboard is an educational simulation for demonstrating memory reliability and parity-based error detection.

Problem

Memory data can become corrupted because of bit errors during storage or transfer.

Solution

The simulator adds a parity bit, optionally corrupts the stored data, and checks the parity during a read operation.

Digital Concept

Even parity: the total number of 1s including the parity bit should be even.

Technology

HTML, CSS and JavaScript with reproducible synthetic memory data.
